## 🇷🇺 Русский

**Flux** — это легковесный инструмент для обхода сетевых ограничений и DPI, объединяющий в себе возможности `winws2` (Zapret) и встроенного прокси-сервера в одном удобном приложении. 

Проект создан по личной инициативе автора для упрощения настройки и повышения стабильности интернет-соединения в условиях жестких сетевых ограничений.

> ⚠️ **Важно:** Проект в настоящее время находится на стадии **бета-тестирования (Beta)**. Некоторые функции активно дорабатываются.

### ✨ Ключевые особенности и преимущества

* **Два инструмента в одном:** Больше не нужно запускать отдельно службы обхода DPI и сторонкие прокси-серверы — всё работает внутри одного приложения.
* **Автогенерация конфигурации:** Утилита автоматически анализирует текущие сетевые параметры, подбирает оптимальный конфиг для обхода DPI и проверяет успешность подключения.
* **Интеграция с winws2:** Проверенные временем алгоритмы обхода DPI, адаптированные для удобного использования.

### 🛠 Статус разработки

* [🔄] **Обход DPI (winws2):** Базовый функционал работает стабильно. В планах — улучшение алгоритмов автоподбора параметров для сложных провайдеров.
* [⏳] **Модуль Прокси:** В процессе активной разработки и интеграции.
* [⚙️] **Конфигуратор:** Автогенерация конфигов уже тестируется и показывает хорошие результаты.

### 🚀 Как запустить и использовать

1. Перейдите в раздел **Releases** и скачайте последнюю версию.
2. Запустите приложение (для корректной работы `winws2` могут потребоваться права администратора).
3. Программа автоматически просканирует сеть и создаст оптимальный рабочий конфиг.

## 🇺🇸 English

**Flux** is a lightweight tool designed to bypass network restrictions and DPI, combining the power of `winws2` (Zapret) and a built-in proxy server into a single, seamless application.

This is a personal initiative project aimed at simplifying network configurations and ensuring stable internet access under strict censorship or filtering.

> ⚠️ **Note:** The project is currently in the **Beta** stage. Many features are under active development.

### ✨ Key Features & Advantages

* **All-in-One Utility:** No need to run separate DPI bypass scripts and third-party proxy clients. Everything you need is packed into a single app.
* **Auto-Configuration & Verification:** The tool automatically scans your current network, generates an optimal bypass configuration, and verifies successful connectivity.
* **Powered by winws2:** Utilizes robust DPI bypass mechanics tailored for ease of use.

### 🛠 Development Status

* [🔄] **DPI Bypass (winws2):** Core features are up and running. Further polishing and optimization of connection strategies are planned.
* [⏳] **Proxy Module:** Currently being implemented and fine-tuned.
* [⚙️] **Auto-Configurator:** Live and undergoing testing with positive success rates.

### 🚀 Getting Started

1. Go to the **Releases** section and download the latest build.
2. Launch the application (Administrator privileges may be required for `winws2` core features).
3. Allow the app to automatically adapt to your current network environment and enjoy unrestricted access.
