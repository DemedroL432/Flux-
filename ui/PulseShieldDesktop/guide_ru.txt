Справочник PulseShield — обход DPI и локальный прокси

О ЧЁМ ПРОГРАММА
PulseShield объединяет два независимых контура:
• Прокси (sing-box) — маршрутизация трафика по правилам JSON, VLESS-сервер.
• DPI (winws2 / goodbyedpi) — попытка обхода блокировок на уровне провайдера. Работает отдельно от прокси; оба можно включать одновременно.

ПЕРВЫЙ ЗАПУСК
• Приложение желательно запускать от имени администратора: для DPI и смены DNS нужны права на системные настройки.
• Рядом с PulseShield.exe должна лежать папка zapret (winws2.exe, пресеты, lists, lua). Portable-сборка копирует её автоматически.

ВКЛАДКА «ПАНЕЛЬ»
• Прокси — включает локальный mixed-прокси на выбранном порту (по умолчанию 8080). Системный режим прокси Windows переключается вместе с ядром.
• DPI — включает обход DPI по выбранному профилю. Если процесс не виден, смотрите вкладку «Логи».
• График скорости — оценка трафика через локальный прокси (не «чистые» байты ядра), удобно для проверки, что приложения ходят в прокси.

ВКЛАДКА «СЕРВЕРЫ»
• Добавьте VLESS-ссылку — сервер появится в списке. Активный сервер используется ядром sing-box.
• «Сделать активным» — переключает конфигурацию; при включённом прокси настройки применяются автоматически.

ВКЛАДКА «СЕТЬ»
• JSON маршрутизации — правила: какие домены/IP идут в proxy, direct или block. Есть профили маршрутизации; можно импортировать/экспортировать JSON.
• Кнопка «Применить правила сети» сохраняет JSON в активный профиль.

ВКЛАДКА «DPI»
• Профиль — список собирается из файлов .txt в папке zapret/presets (включая подпапку custom). Удалённые с диска пресеты исчезают из списка после обновления (перезайдите на вкладку или перезапустите приложение).
• Импорт DPI-конфига — копирует .txt в zapret/presets/custom для корректных относительных путей к lists/.

ВКЛАДКА «ЛОГИ»
• Отдельные блоки: ошибки ядра/DPI, отфильтрованные строки соединений, полный хвост логов.
• «Очистить» — обнуляет файлы логов на диске (удобно перед новым тестом).
• Сообщения вроде «connection closed» при закрытии вкладок часто нормальны.

ВКЛАДКА «ДИАГНОСТИКА»
• Самопроверка — пути к конфигу, ядру, папке DPI, статус процессов.
• Архив диагностики — ZIP для отправки разработчику.

НАСТРОЙКИ
• Тема и акцентный цвет — визуальные настройки; «Применить» фиксирует выбор.
• Порт прокси — если 8080 занят, смените и примените, затем снова включите прокси.
• DNS — пресеты «Авто», «Xbox DNS» или свои адреса; применение требует прав администратора.
• Telegram — укажите ссылку (https://t.me/...) и отображаемое имя канала; по имени можно открыть страницу канала.

ЗАКРЫТИЕ ОКНА
• Крестик сворачивает окно в трей (приложение не закрывается). Полный выход — из меню трея или кнопки «Полностью выйти» в настройках.

ОГРАНИЧЕНИЯ
• Эффективность DPI зависит от провайдера и списков; универсального «включил и всё работает» не бывает.
• При проблемах приложите логи и результат диагностики.
